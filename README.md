Amber Yard — a round-based three.js tactical FPS: you attack with two bot team-mates against four defender bots on an original 36×28 m industrial yard with bomb sites A and B. Plant the bomb or eliminate the other team; first to 4 rounds takes the match. Four weapons, HE grenades, a buy menu with round-by-round economy, bots that patrol lanes, hold angles, react to gunfire and plant/defuse, plus a full HUD with health, ammo, timer, score, money, kill feed and minimap.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No build step, no network: static files only.
